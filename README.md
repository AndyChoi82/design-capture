## What is Design Capture?

Design Capture is a Figma plugin + Chrome extension that converts any web page into native Figma design assets. No screenshots. No copy-pasting. Real, editable Figma frames, text, fills, and shadows.

**Keywords**: web to figma, html to figma, figma plugin, design capture, convert website to figma, figma import, css to figma, 피그마 웹 캡처, 웹페이지 피그마 변환

---

## How It Works

1. **Run** the Design Capture Server app (Mac & Windows — no terminal needed)
2. **Click Capture** in the Chrome extension — collects DOM, CSS, fonts, and colors
3. **Click Import** in the Figma plugin — creates native Frames, Text, Fills, and Shadows in Figma

---

## Features

- ✅ Full CSS conversion — gradients, border-radius, box-shadow
- ✅ CSS variable resolution — design tokens converted to real values
- ✅ Form elements — Input, Select, Checkbox with values and placeholders
- ✅ Real-time progress — track conversion of hundreds of nodes live
- ✅ Canvas/chart rendering — graphs captured as images
- ✅ Multilingual UI — EN, 日本語, 中文, ES, 한국어
