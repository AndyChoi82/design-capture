FAQ

Frequently Asked Questions
Chrome 확장은 브라우저 보안 정책상 캡쳐 데이터를 Figma로 직접 전달할 수 없습니다. Design Capture Server는 내 PC에서만 실행되는 로컬 중계 서버로, 데이터가 외부 서버를 거치지 않아 안전합니다. Due to browser security policies, Chrome extensions can't send captured data directly to Figma. Design Capture Server is a local relay that runs only on your machine — no data is sent to any external server.
네. Chrome 확장은 현재 브라우저에 보이는 상태 그대로 캡쳐합니다. 사내 대시보드, 어드민 페이지, 구독 서비스 UI 등 외부에서 접근 불가한 화면도 모두 캡쳐할 수 있습니다. Yes. The Chrome extension captures exactly what you see in your browser — including internal dashboards, admin panels, and any private UI that can't be accessed externally.
무료 플랜은 총 20건 변환이 가능합니다. 라이센스($9.99/년) 구매 시 무제한으로 사용할 수 있으며 2대 기기에서 동시 사용 가능합니다. The free plan includes 20 conversions total. A license ($9.99/year) gives you unlimited conversions on up to 2 devices.
Apple Developer Program 공증을 거치지 않은 앱에 macOS가 기본으로 표시하는 경고입니다. 시스템 설정 → 개인정보 보호 및 보안 → '그래도 열기'를 클릭하면 정상 실행됩니다. This is a standard macOS warning for apps not notarized through Apple's Developer Program. Go to System Settings → Privacy & Security → Open Anyway to proceed.
Chrome만 지원합니다. Chrome 확장으로 개발된 도구입니다. Chrome only. Design Capture is built as a Chrome extension.
DOM 구조 기반으로 Frame, Text, Rectangle 등 네이티브 Figma 레이어가 생성됩니다. Fill(그라디언트 포함), Shadow, Border Radius, 폰트 굵기·자간 등 CSS 속성이 Figma 속성으로 정확히 매핑되며, CSS 변수(var(--color))도 실제 값으로 자동 해석됩니다. Native Figma layers are created based on DOM structure: Frames, Text, Rectangles and more. CSS properties including gradients, shadows, border-radius, and font details are accurately mapped to Figma. CSS variables (var(--color)) are automatically resolved to their real values.
