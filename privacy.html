Privacy Policy — Design Capture
Effective Date: May 28, 2026

Design Capture(이하 "본 서비스")는 사용자의 개인정보를 소중히 여기며 관련 법령을 준수합니다.
Design Capture (hereinafter "the Service") values your privacy and complies with applicable laws.

1. 수집하는 정보 / Information We Collect

Chrome Extension사용자가 명시적으로 '캡처' 버튼을 누를 때에만 현재 탭의 DOM, CSS, 폰트, 색상 정보를 일시적으로 추출합니다. 외부 서버로 전송되지 않으며 변환 완료 후 즉시 소멸됩니다.
The extension temporarily extracts DOM, CSS, fonts, and color data from the active tab only when the user explicitly clicks Capture. This data is never sent to external servers and is destroyed after conversion.

License라이센스 구매 시 이메일 주소가 결제 처리를 위해 수집됩니다. 결제 및 라이센스 발급은 Paddle이 처리하며, 개발자는 결제 카드 정보에 접근하지 않습니다.
When purchasing a license, your email address is collected for payment processing. Payments and license issuance are handled by Paddle. The developer does not have access to your payment card details.

Figma Plugin라이센스 활성화 시 Figma User ID가 라이센스 인스턴스 식별에 사용됩니다. 이 정보는 라이센스 유효성 검증 외의 목적으로 사용되지 않습니다.
During license activation, your Figma User ID is used to identify the license instance. This information is used solely for license validation purposes.

2. 데이터 저장 및 전송 / Data Storage and Transmission

  • 캡처된 웹 페이지 데이터는 외부 서버에 저장되지 않습니다. / Captured web page data is not stored on external servers.
  • 데이터는 사용자 PC의 로컬 서버(localhost:3721)를 통해서만 전달됩니다. / Data is transmitted only through the local server (localhost:3721) on the user's PC.
  • 라이센스 키 및 Figma User ID는 라이센스 검증 서버(Railway)에 안전하게 전송됩니다. / License keys and Figma User ID are securely transmitted to the license validation server (Railway).
  • 이메일 주소 등 결제 정보는 Paddle의 개인정보처리방침에 따라 처리됩니다. / Payment information including email address is handled according to Paddle's privacy policy.

3. 데이터 보유 기간 / Data Retention

캡처 데이터는 변환 완료 즉시 소멸됩니다. 라이센스 관련 데이터(이메일, 라이센스 키)는 라이센스 유효 기간 동안 보관되며 만료 후 삭제됩니다.
Captured data is destroyed immediately after conversion. License-related data (email, license key) is retained for the duration of the license and deleted upon expiry.

4. 제3자 제공 / Third-Party Sharing

수집된 정보는 다음의 경우를 제외하고 외부에 제공되지 않습니다.
Collected information is not shared with third parties except as follows.

  • Paddle — 결제 처리 및 라이센스 발급 / Payment processing and license issuance
  • Railway — 라이센스 유효성 검증 서버 운영 / License validation server hosting

5. 쿠키 및 추적 / Cookies and Tracking

본 서비스는 쿠키 또는 추적 기술을 사용하지 않습니다.
This service does not use cookies or tracking technologies.
