Privacy Policy — Design Capture

Design Capture(이하 "본 확장 프로그램")는 사용자의 개인정보를 소중히 여기며, 관련 법령을 준수합니다. 본 방침은 본 확장 프로그램이 브라우저 내에서 데이터를 어떻게 처리하는지 안내합니다.

Design Capture (hereinafter referred to as "the Extension") values your privacy and complies with relevant laws. This policy explains how the Extension handles data within your browser.

1. 개인정보의 수집 및 이용 목적 (Data Collection and Purpose)

본 확장 프로그램은 사용자가 명시적으로 '캡처' 버튼을 누른 순간에 한하여, 현재 활성화된 탭의 웹 페이지 구조(DOM), CSS 스타일, 폰트, 색상 정보만을 일시적으로 접근 및 추출합니다. 이 데이터는 웹 UI를 Figma 디자인 에셋으로 변환하기 위한 목적으로만 사용됩니다.

The Extension temporarily accesses and extracts only the structure (DOM), CSS styles, fonts, and color information of the currently active tab when the user explicitly clicks the 'Capture' button. This data is used solely for the purpose of converting web UI into Figma design assets.

2. 데이터의 저장 및 전송 방식 (Data Storage and Transmission)

  • 서버 전송 없음 (No External Server Transmission): 캡처된 모든 웹 페이지 데이터는 개발자의 외부 서버나 제3의 서버로 절대 전송되거나 저장되지 않습니다.
  • 로컬 처리 (Local Processing): 추출된 데이터는 사용자의 PC 내부에서 구동되는 로컬 릴레이 서버(localhost)를 통해서만 Figma 플러그인으로 안전하게 전달되며, 변환 작업이 완료되면 즉시 소멸됩니다.
• All captured webpage data is NEVER transmitted to or stored on the developer's external servers or any third-party servers.
• The extracted data is transmitted safely to the Figma plugin ONLY through the local relay server (localhost) running on the user's PC and is destroyed immediately after the conversion.

3. 개인정보의 보유 및 이용기간 (Data Retention)

본 확장 프로그램은 어떠한 형태의 개인 식별 정보, 웹 서핑 이력, 민감한 데이터를 수집하거나 서버에 저장하지 않으므로, 보유하는 개인정보 자체가 존재하지 않습니다.

Since the Extension does not collect or store any form of personally identifiable information, web browsing history, or sensitive data on a server, no personal data is retained.

4. 제3자 제공 및 위탁 (Third-Party Sharing)

본 확장 프로그램은 수집된 정보를 외부에 제공하거나 위탁하지 않습니다.

The Extension does not provide or entrust collected information to external parties.
